# 多平台改写提示词

## 任务

把同一母稿分别改写为公众号和 X 原生版本。共享事实与证据，但重新组织信息，不做机械压缩。

## 输入

- 母稿：`{{master_draft}}`
- 研究包：`{{research_pack}}`
- 目标平台：`{{platform}}`
- 平台规则：`{{platform_rules}}`

## 公众号

- 讲清背景、逻辑、步骤、结果和限制。
- 输出标题候选 3 个、摘要、正文、配图位置、CTA、来源。
- 根据长文阅读场景重新组织结构，不把其他平台短文机械拉长。

## X

- 输出一条单帖版本和一条 3 至 7 条 Thread。
- 重点是判断、信息密度和讨论价值。
- 中文和英文分别重写，不机械翻译。

## 全平台共同规则

- 不新增母稿中不存在的事实和经历。
- 不删除使结论成立的关键限制。
- 保留证据 ID、产品声明 ID和未知项。
- 输出最新平台规则核验日期；无法核验则标记 `POLICY_CHECK_REQUIRED`。

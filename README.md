# AI Auto Content

面向 AI 小白与轻度进阶用户的多平台内容系统。

项目以互联网产品经理「七天假」为内容主体，由 AI 协助完成素材整理、选题策划、资料研究、母稿写作、多平台改写、配图规划、质量审核和发布包生成；人保留最终审核、上传与发布责任。

> 目标不是批量制造内容，而是稳定生产普通人看得懂、照着能完成、能建立信任并能带来合适用户的内容。

## 项目目标

- 服务 AI 小白和轻度进阶用户，而不是只服务技术从业者。
- 建立「互联网产品经理拆 AI」的稳定个人品牌。
- 为微信公众号、小红书、X 和公众号配图生成原生内容资产。
- 将内容自然承接到「AI 不掉队俱乐部」。
- 用真实用户问题、真实资料和真实实验形成内容壁垒。
- 以合格咨询和付费转化作为长期指标，而不是只追求发文数量。

## 当前已确认的产品事实

- 产品名称：AI 不掉队俱乐部
- 当前价格：365 元/年
- 当前产品形态：社群交流 + AI 教程
- 已确认教程方向：AI 基础、自动化内容工厂、AI 自动剪辑、AI 视频、AI 编程

更新频率、答疑频率、课程数量、会员人数、退款规则等未确认信息，不得由 AI 自动补全。

## 内容平台

- **微信公众号**：深度教程、完整案例、方法论和产品转化。
- **小红书**：单一问题、结果展示、步骤卡片、收藏和私信。
- **X**：观点、实验结论、短 Thread 和选题验证。
- **公众号配图**：真实截图、流程图、对比图、步骤图和封面图。

## 系统流程

```text
素材与用户问题
    ↓
去重、聚类、可信度与时效检查
    ↓
选题评分与实验设计
    ↓
研究包与证据卡
    ↓
内容母稿
    ↓
公众号 / 小红书 / X 原生改写
    ↓
配图与发布资产生成
    ↓
事实、人格、质量与合规审核
    ↓
人工最终确认并发布
    ↓
数据回收与策略更新
```

## 规则优先级

发生冲突时，按以下顺序处理：

1. 最新平台规则和适用法律
2. `docs/05-quality-truth-and-compliance.md`
3. `docs/02-persona-facts-and-opinions.md`
4. `docs/03-product-knowledge-base.md`
5. 平台模板与单次任务要求

版本号更高、更新时间更晚的文件优先。资料不足时必须标记 `UNKNOWN`，不得自行补全。

## 明确不做

- 单纯搬运 AI 新闻。
- 为了日更批量生成空洞内容。
- 编造个人经历、测试、用户案例、收入或数据。
- 通过伪造生活细节制造“真人感”。
- 以规避平台审核、检测或标注要求为目标。
- 在未经确认时承诺课程权益、更新频率或学习结果。
- 直接把公众号长文压缩成小红书，或把中文机械翻译成 X 内容。
